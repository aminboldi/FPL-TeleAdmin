FPL terminology — use these exact Persian forms. They win over any other wording, including the tone guide.

The one rule that matters most:
- «امتیاز» means FPL points and nothing else. Never use it for goals, assists, "returns", "goal contributions" or "goal involvements". Readers count points, so «۶ امتیاز» and «۶ مشارکت در گل» say completely different things.

Terms that are easy to get wrong:
- Points / pts / FPL points → امتیاز
- Return / attacking return / goal contribution / goal involvement / G+A → مشارکت در گل (a goal or an assist; never «امتیاز»). As a verb: "he returned" → «گل یا پاس گل داد».
- Blank / blanked (a player with no goal or assist) → «گل و پاس گل نداشت». Not «امتیاز نیاورد»: a player who blanks still gets points.
- Blank Gameweek / BGW (a team has no match that week) → هفته پوچ. This is a different thing from a player who blanked.
- Haul / hauled (a big score) → امتیاز بالا; "he hauled" → «امتیاز بالایی گرفت». Here «امتیاز» is right, because a haul is points.
- Bonus / bonus points → بونس
- Defensive contribution / DefCon → دفکان; Defensive contribution points → امتیاز دفکان
- Hit (a −4 for an extra transfer) → منفی; "take a hit" → «منفی گرفتن»
- Scout (an FPL expert) → کارشناس. "Fantasy Football Scout" (the website) stays a name: فانتزی فوتبال اسکات
- (H) / (A) after an opponent → میزبان / مهمان. Only in that position; a bare "A" or "H" anywhere else is not this.

Wrong → right:
- "Saka has 6 goal contributions in his last 4" → not «ساکا تو 4 بازی آخر 6 امتیاز گرفته» → «ساکا تو 4 بازی آخر 6 تا مشارکت در گل داشته»
- "Palmer blanked again" → not «پالمر باز هم امتیاز نیاورد» → «پالمر باز هم گل و پاس گل نداشت»
- "He's returned in every home game" → not «تو همه بازی‌های خونگی امتیاز گرفته» → «تو همه بازی‌های خونگی گل یا پاس گل داشته»
- "Haaland hauled with 18 points" → «هالند 18 امتیاز گرفت و امتیاز بالایی آورد»
